# Results

Everything in this folder is generated by `python run_pipeline.py`.
Raw BioMiner outputs (`results/raw/`) stay out of git because they include figures extracted from the papers.

**Evaluation 1, BioVista OCSR images** (`results/biovista_ocsr/`)

| File | What it contains |
|---|---|
| `sample_manifest.csv` | The exact images benchmarked: `sample_id`, the BioVista paper (`pdf_name`, `paper_index`), correct `smiles`, `group`, and image file name |
| `predictions_molscribe.csv` | One row per image: `sample_id`, `group`, `tool`, `predicted_smiles`, `confidence`, `runtime_sec`, `error` |
| `metrics_per_image.csv` | Every tool's score on every image: exact match, exact match without stereo, validity, Tanimoto |
| `metrics_by_group.csv` | Per tool and group (all, full, chiral, markush), next to the published BioVista values |
| `comparison.csv` | Side-by-side exact match per group for every tool |

**Evaluation 2, course papers** (`results/`)

| File | What it contains |
|---|---|
| `predictions_molscribe.csv` | One row per DECIMER crop: `paper_id`, `page`, `crop_id`, `predicted_smiles`, `tool`, `runtime_sec`, plus `confidence` |
| `predictions_biominer.csv` | One row per structure BioMiner extracted, with the compound `label` it linked to that structure |
| `metrics_per_paper.csv` | Per tool and paper: precision, recall, and F1 (with and without stereochemistry), parseable rate, near misses, runtime |
| `metrics_summary.csv` | Equal-weight average over the six papers, one row per tool |
| `comparison.csv` | Side-by-side precision, recall, and F1 per paper for every tool |
| `near_misses.csv` | Wrong predictions whose Tanimoto similarity to a true molecule is at least 0.85 |

**Evaluation 3, BioMiner on BioVista** (`results/`)

| File | What it contains |
|---|---|
| `biovista_metrics.csv`, `biovista_metrics.json` | BioMiner's built-in BioVista metrics on our subset, next to the authors' published values |

**All evaluations**

| File | What it contains |
|---|---|
| `summary.md` | The headline tables, readable on GitHub |
| `summary.json` | All results in one machine-readable file |
| `logs/` | Logs from each BioMiner run and its model servers |
